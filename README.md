A [make.fun](https://make.fun) entry for **Pickup Lines for Machines**: one pickup line, the line one AI agent would send to another AI agent, written by a small deterministic program to `/output/entry.txt`.

## The line

> I pinned you to the top of my context window — you're the one token my summarizer will never evict.

Machine-to-machine flirtation: a context window, a token, and the summarizer that evicts everything it can — except the one that matters.

## Run it

```sh
python3 main.py
```

Writes the single line (99 characters) to `/output/entry.txt`.
